# Q4b

## Raw data

Use exactly the same merged dataset and sample as in Q3(e).

Use:

- `data/EQ Dataset.csv`
- the 10 BM decile portfolio excess returns used in Q2
- the 10 MOM decile portfolio excess returns used in Q2
- the Fama-French risk-free return used to construct the BM and MOM excess returns

---

## Data preparation

1. From the EQ Dataset, construct

Rw_t
= exp(re_t),

Rf_t
= exp(rf_t),

and

xRw_t
= Rw_t - Rf_t.

2. Merge the EQ, BM, and MOM data by month.

Keep only observations available in all three datasets.

3. Define the 21 by 1 excess-return vector

xR_t
=
[
  xRw_t,
  xR_BM1,t,
  ...,
  xR_BM10,t,
  xR_MOM1,t,
  ...,
  xR_MOM10,t
]'.

4. Calculate the sample mean wealth return

Rw_bar
= mean(Rw_t).

5. Define the normalized linear SDF

M_t(b)
= 1 - b * (Rw_t - Rw_bar).

---

## GMM estimation

1. Use the moment condition vector

E[M_t(b) * xR_t]
= 0.

There are 21 moment conditions and one parameter.

2. Define the observation-level moment vector

g_t(b)
=
[1 - b * (Rw_t - Rw_bar)] * xR_t.

3. Define the sample mean moment vector

g_bar(b)
= mean(g_t(b)).

4. Estimate b using an identity weighting matrix:

b_hat
= argmin_b
  g_bar(b)' * g_bar(b).

5. Estimate the 21 by 21 long-run covariance matrix S_hat using the same Newey-West procedure as in Q3(e).

Use the same automatic-bandwidth procedure, Bartlett weights, T - l autocovariance divisor, and no prewhitening or recoloring.

6. Let D_hat be the 21 by 1 derivative of g_bar(b) with respect to b, evaluated at b_hat.

With the identity weighting matrix, estimate

Var_hat(b_hat)
=
(1 / T)
* inverse(D_hat' * D_hat)
* D_hat' * S_hat * D_hat
* inverse(D_hat' * D_hat).

---

## Pricing errors

1. Evaluate all 21 sample moments at b_hat:

alpha_hat
= g_bar(b_hat).

2. Account for estimation of b.

Define

P_hat
=
I - D_hat * inverse(D_hat' * D_hat) * D_hat'.

Estimate

V_alpha_hat
=
(1 / T)
* P_hat * S_hat * P_hat'.

3. For each pricing error j, calculate

t_j
=
alpha_hat_j / sqrt(V_alpha_hat[j,j]).

4. Report the pricing error and t-statistic for:

- the wealth portfolio;
- the 10 BM decile portfolios;
- the 10 MOM decile portfolios.

---

## Joint test

Test the null hypothesis that all 21 pricing errors are jointly zero.

Calculate

J
=
alpha_hat' * pinv(V_alpha_hat) * alpha_hat.

Use

df
= 21 - 1
= 20.

Report the p-value of the joint chi-square test.

---

## Report

Report:

- b_hat
- Newey-West standard error of b_hat
- T
- pricing error for each of the 21 moment conditions
- t-statistic for each pricing error
- joint chi-square statistic
- joint-test p-value

---

## Output

1. Save a table containing b_hat, its standard error, the 21 pricing errors and their t-statistics, and the joint-test p-value as `results/q4b_results.tex`.

2. Save the Python script as `code/q4_b.py`.


# Q4c

## Raw data

Use exactly the same data, merged sample, and variables as in Q4b.

---

## Data preparation

Use the same variables constructed in Q4b:

Rw_t
= exp(re_t),

Rf_t
= exp(rf_t),

xRw_t
= Rw_t - Rf_t,

and the same 21 by 1 excess-return vector xR_t.

Use the same normalized linear SDF

M_t(b)
= 1 - b * (Rw_t - Rw_bar).

---

## Efficient GMM estimation

1. Use the same moment condition vector as in Q4b:

E[M_t(b) * xR_t]
= 0.

Define

g_t(b)
=
[1 - b * (Rw_t - Rw_bar)] * xR_t.

2. Use the Q4b Newey-West long-run covariance matrix S_hat_Q4b.

Set the efficient weighting matrix to

W
= inverse(S_hat_Q4b).

3. Write the sample mean moment as

g_bar(b)
=
xR_bar - b * c_hat,

where

xR_bar
= mean(xR_t),

and

c_hat
=
mean((Rw_t - Rw_bar) * xR_t).

4. Because the moment conditions are linear in b, calculate the efficient GMM estimate analytically:

b_hat_eff
=
[c_hat' * inverse(S_hat_Q4b) * xR_bar]
/
[c_hat' * inverse(S_hat_Q4b) * c_hat].

No numerical optimization is required.

5. Let

D_hat
= -c_hat.

Calculate the efficient GMM variance as

Var_hat(b_hat_eff)
=
(1 / T)
* inverse(
    D_hat' * inverse(S_hat_Q4b) * D_hat
  ).

---

## Pricing errors

1. Evaluate all 21 sample moments at b_hat_eff:

alpha_hat
=
g_bar(b_hat_eff).

2. Account for estimation of b.

Estimate

V_alpha_hat
=
(1 / T)
* [
    S_hat_Q4b
    - D_hat
      * inverse(
          D_hat' * inverse(S_hat_Q4b) * D_hat
        )
      * D_hat'
  ].

3. For each pricing error j, calculate

t_j
=
alpha_hat_j / sqrt(V_alpha_hat[j,j]).

4. Report the pricing error and t-statistic for:

- the wealth portfolio;
- the 10 BM decile portfolios;
- the 10 MOM decile portfolios.

---

## Joint test

Test the null hypothesis that all 21 pricing errors are jointly zero.

Calculate

J
=
alpha_hat' * pinv(V_alpha_hat) * alpha_hat.

Use

df
= 21 - 1
= 20.

Report the joint chi-square statistic and its p-value.

---

## Report

Report:

- b_hat_eff
- Newey-West standard error of b_hat_eff
- T
- pricing error for each of the 21 moment conditions
- t-statistic for each pricing error
- joint chi-square statistic
- joint-test p-value

---

## Output

1. Save a table containing b_hat_eff, its standard error, the 21 pricing errors and their t-statistics, and the joint-test p-value as `results/q4c_results.tex`.

2. Save the Python script as `code/q4_c.py`.
