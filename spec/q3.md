# Q3b

## Raw data

Use `data/EQ Dataset.csv`.

Use:

- `re` = annual log equity market return
- `rf` = annual log risk-free return

The dataset has monthly observations, but `re` and `rf` are annual returns.

---

## Data preparation

1. Construct the gross wealth return

Rw_t
= exp(re_t).

2. Construct the gross risk-free return

Rf_t
= exp(rf_t).

3. Construct the excess return on the wealth portfolio

xRw_t
= Rw_t - Rf_t.

4. Use the unconditional SDF moment condition

E[Rw_t^(-gamma) * xRw_t]
= 0.

Define the observation-level moment

g_t(gamma)
= Rw_t^(-gamma) * xRw_t,

and the sample moment

g_hat(gamma)
= mean(g_t(gamma)).

5. Estimate gamma by GMM.

Since there is one parameter and one moment condition, choose gamma such that

g_hat(gamma)
= 0.

6. Calculate the standard error of gamma using the GMM asymptotic variance.

Estimate the long-run variance S of the moment using Newey-West (1987, 1994).
For the data-driven Newey-West estimator, use a Bartlett kernel without
prewhitening or recoloring.

Let

u_t
= g_t(gamma_hat) - mean(g_t(gamma_hat)).

For lag l, calculate the autocovariance as

Gamma_hat_l
= (1 / (T - l))
  * sum_{t=l+1}^T u_t * u_{t-l}.

Set the pilot lag to

q
= floor(4 * (T / 100)^(2/9)).

Using the pilot autocovariances, calculate

s0_hat
= Gamma_hat_0
  + 2 * sum_{l=1}^q Gamma_hat_l,

and

s1_hat
= 2 * sum_{l=1}^q l * Gamma_hat_l.

Then calculate the Newey-West (1994) plug-in constant

const_hat
= 1.1447
  * [ (s1_hat / s0_hat)^2 ]^(1/3).

Calculate the unrounded bandwidth

bandwidth_unrounded
= const_hat * T^(1/3),

and set the final bandwidth to

L
= floor(bandwidth_unrounded).

Using Bartlett weights

w_l
= 1 - l / (L + 1),

estimate the long-run variance as

S_hat
= Gamma_hat_0
  + 2 * sum_{l=1}^L w_l * Gamma_hat_l.

7. Report

- gamma_hat
- Newey-West standard error of gamma_hat
- q
- s0_hat
- s1_hat
- const_hat
- bandwidth_unrounded
- L

---

## Output

1. report the estimate of gamma and its Newey-West standard error;
2. report the automatic-bandwidth diagnostics listed above;
3. save the Python script as `code/q3_b.py`.




# Q3c

## Raw data

Use `data/EQ Dataset.csv`.

Reconstruct the restricted out-of-sample expected excess equity return forecast
from Question 2(e) of Problem Set 1 using the identical `EQ Dataset.csv` and the
same expanding-window procedure as the PS1 code in
`/Users/melody/Dropbox/PhD/Courses/Asset Pricing/BUSFIN-8200-PS1`.

Use:

- `re` = annual log equity market return
- `rf` = annual log risk-free return
- the out-of-sample forecast of excess equity return from PS1 Q2(e)

---

## Data preparation

1. Construct the gross wealth return

Rw_t
= exp(re_t).

2. Construct the gross risk-free return

Rf_t
= exp(rf_t).

3. Construct the excess return on the wealth portfolio

xRw_t
= Rw_t - Rf_t.

4. Calculate the unconditional variance of the equity return over the full sample:

sigma_e^2
= Var(Rw_t).

Use the entire December 1927 through December 2021 sample and divisor T
(`ddof=0`) for this variance.

5. Construct the trading instrument

z_{t-1}
= E^OS_{t-1}[xRe_t] / sigma_e^2.

Align the out-of-sample forecast so that the forecast formed at t-1 is matched with the realized excess return at t.

Use forecasts dated December 1940 through December 2021. The resulting Q3(c)
estimation sample has T = 973 observations.

6. Construct the managed-portfolio excess return

z_{t-1} * xRw_t.

---

## GMM estimation

1. Use the two unconditional SDF moment conditions

E[Rw_t^(-gamma) * xRw_t]
= 0,

and

E[Rw_t^(-gamma) * z_{t-1} * xRw_t]
= 0.

2. Define the moment vector

g_t(gamma)
=
[
  Rw_t^(-gamma) * xRw_t,
  Rw_t^(-gamma) * z_{t-1} * xRw_t
]'.

3. Define the sample mean moment vector

g_bar(gamma)
= mean(g_t(gamma)).

4. Estimate gamma by GMM using the identity weighting matrix:

gamma_hat
= argmin_gamma
  g_bar(gamma)' * g_bar(gamma).

Minimize over all real values of gamma; do not impose a nonnegativity or other
parameter constraint.

5. Calculate the standard error of gamma_hat using the same Newey-West procedure as in Q3b.

Recalculate the automatic bandwidth on the Q3(c) estimation sample. Apply the
Q3(b) scalar Newey-West (1994) bandwidth procedure to the centered first moment
series, then use the resulting common bandwidth L for every element of the 2 by
2 long-run covariance matrix S_hat. Use Bartlett weights, the `T - l`
autocovariance divisor, and no prewhitening or recoloring, as in Q3(b).

Let D_hat be the 2 by 1 derivative of g_bar(gamma) with respect to gamma,
evaluated at gamma_hat. With the identity GMM weighting matrix, estimate

Var_hat(gamma_hat)
= (1 / T)
  * (D_hat' * D_hat)^(-1)
  * D_hat' * S_hat * D_hat
  * (D_hat' * D_hat)^(-1).

---

## Pricing errors

1. Evaluate the two sample moment conditions at gamma_hat.

These are the pricing errors:

alpha_hat
= g_bar(gamma_hat).

2. Calculate the standard error and t-statistic for each pricing error.

Account for estimation of gamma. Define

P_hat
= I - D_hat * (D_hat' * D_hat)^(-1) * D_hat'.

Estimate the covariance matrix of the pricing errors as

V_alpha_hat
= (1 / T) * P_hat * S_hat * P_hat'.

For each moment j, calculate

t_j
= alpha_hat_j / sqrt(V_alpha_hat[j,j]).

3. Report the pricing error and t-statistic for:

- the wealth portfolio moment;
- the managed-portfolio moment.

---

## Joint test

Test the null hypothesis that the two pricing errors are jointly zero.

Use the chi-square pricing-error test based on the estimated covariance matrix of the pricing errors.

Calculate

J
= alpha_hat' * pinv(V_alpha_hat) * alpha_hat,

where `pinv` is the Moore-Penrose pseudoinverse. Use one degree of freedom,
equal to the number of moments minus the number of estimated parameters.

Report the p-value of the joint test.

---

## Report

Report:

- gamma_hat
- Newey-West standard error of gamma_hat
- pricing error for each moment condition
- t-statistic for each pricing error
- p-value for the joint chi-square test
- T

---

## Output

1. save a table containing gamma_hat, its standard error, the two pricing errors and their t-statistics, and the joint-test p-value as `results/q3c_results.tex`;
2. save the Python script as `code/q3_c.py`.




# Q3d

## Raw data

Use exactly the same data, reconstructed PS1 Q2(e) forecasts, estimation sample,
trading instrument, and moment conditions as in Q3c.

Use:

- `re` = annual log equity market return
- `rf` = annual log risk-free return
- the reconstructed out-of-sample forecast of excess equity return from PS1 Q2(e)

Use the same Q3(c) estimation sample from December 1940 through December 2021,
with T = 973 observations.

---

## Data preparation

Use the same variables constructed in Q3c:

Rw_t
= exp(re_t).

Rf_t
= exp(rf_t).

xRw_t
= Rw_t - Rf_t.

Use the same trading instrument

z_{t-1}
= E^OS_{t-1}[xRe_t] / sigma_e^2,

where sigma_e^2 is the full-sample variance of Rw_t using December 1927 through
December 2021 and `ddof=0`.

Construct the managed-portfolio excess return

z_{t-1} * xRw_t.

---

## GMM estimation

1. Use the same two moment conditions as in Q3c:

E[Rw_t^(-gamma) * xRw_t]
= 0,

and

E[Rw_t^(-gamma) * z_{t-1} * xRw_t]
= 0.

Define

g_t(gamma)
=
[
  Rw_t^(-gamma) * xRw_t,
  Rw_t^(-gamma) * z_{t-1} * xRw_t
]'.

2. First step:

Use the Q3(c) identity-weighted GMM estimate and the corresponding Newey-West
long-run covariance matrix S_hat_Q3c.

3. Second step:

Set the weighting matrix to

W
= inverse(S_hat_Q3c).

Estimate gamma using

gamma_hat_2step
= argmin_gamma
  g_bar(gamma)' * inverse(S_hat_Q3c) * g_bar(gamma).

Minimize over all real values of gamma. Do not impose a nonnegativity or other
parameter constraint.

4. Let D_hat be the 2 by 1 derivative of g_bar(gamma) with respect to gamma,
evaluated at gamma_hat_2step.

Calculate the standard error using the efficient two-step GMM variance:

Var_hat(gamma_hat_2step)
= (1 / T)
  * inverse(
      D_hat' * inverse(S_hat_Q3c) * D_hat
    ).

---

## Pricing errors

1. Evaluate the two sample moments at gamma_hat_2step:

alpha_hat
= g_bar(gamma_hat_2step).

2. Calculate pricing-error standard errors accounting for estimation of gamma.

Estimate

V_alpha_hat
= (1 / T)
  * [
      S_hat_Q3c
      - D_hat
        * inverse(
            D_hat' * inverse(S_hat_Q3c) * D_hat
          )
        * D_hat'
    ].

3. For each pricing error j, calculate

t_j
= alpha_hat_j / sqrt(V_alpha_hat[j,j]).

4. Report the pricing error and t-statistic for:

- the wealth portfolio moment;
- the managed-portfolio moment.

---

## Joint test

Test the null hypothesis that the two pricing errors are jointly zero.

Calculate

J
= alpha_hat' * pinv(V_alpha_hat) * alpha_hat.

Use one degree of freedom, equal to the number of moments minus the number of
estimated parameters.

Report the joint chi-square statistic and its p-value.

---

## Report

Report:

- gamma_hat_2step
- Newey-West standard error of gamma_hat_2step
- pricing error for each moment condition
- t-statistic for each pricing error
- joint chi-square statistic
- p-value for the joint test
- T

---

## Output

1. save a table containing gamma_hat_2step, its standard error, the two pricing
   errors and their t-statistics, and the joint-test statistic and p-value as
   `results/q3d_results.tex`;
2. save the Python script as `code/q3_d.py`.
