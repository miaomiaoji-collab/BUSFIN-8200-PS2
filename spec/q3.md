# Q3b

## Raw data

Use `data/EQ Dataset.csv`.

Use:

- `re` = annual log equity market return
- `rf` = annual log risk-free return

The dataset has monthly observations, but `re` and `rf` are annual returns.

---

## Data preparation

1. Construct the gross wealth return

Rw_t
= exp(re_t).

2. Construct the gross risk-free return

Rf_t
= exp(rf_t).

3. Construct the excess return on the wealth portfolio

xRw_t
= Rw_t - Rf_t.

4. Use the unconditional SDF moment condition

E[Rw_t^(-gamma) * xRw_t]
= 0.

Define the observation-level moment

g_t(gamma)
= Rw_t^(-gamma) * xRw_t,

and the sample moment

g_hat(gamma)
= mean(g_t(gamma)).

5. Estimate gamma by GMM.

Since there is one parameter and one moment condition, choose gamma such that

g_hat(gamma)
= 0.

6. Calculate the standard error of gamma using the GMM asymptotic variance.

Estimate the long-run variance S of the moment using Newey-West (1987, 1994).
For the data-driven Newey-West estimator, use a Bartlett kernel without
prewhitening or recoloring.

Let

u_t
= g_t(gamma_hat) - mean(g_t(gamma_hat)).

For lag l, calculate the autocovariance as

Gamma_hat_l
= (1 / (T - l))
  * sum_{t=l+1}^T u_t * u_{t-l}.

Set the pilot lag to

q
= floor(4 * (T / 100)^(2/9)).

Using the pilot autocovariances, calculate

s0_hat
= Gamma_hat_0
  + 2 * sum_{l=1}^q Gamma_hat_l,

and

s1_hat
= 2 * sum_{l=1}^q l * Gamma_hat_l.

Then calculate the Newey-West (1994) plug-in constant

const_hat
= 1.1447
  * [ (s1_hat / s0_hat)^2 ]^(1/3).

Calculate the unrounded bandwidth

bandwidth_unrounded
= const_hat * T^(1/3),

and set the final bandwidth to

L
= floor(bandwidth_unrounded).

Using Bartlett weights

w_l
= 1 - l / (L + 1),

estimate the long-run variance as

S_hat
= Gamma_hat_0
  + 2 * sum_{l=1}^L w_l * Gamma_hat_l.

7. Report

- gamma_hat
- Newey-West standard error of gamma_hat
- q
- s0_hat
- s1_hat
- const_hat
- bandwidth_unrounded
- L

---

## Output

1. report the estimate of gamma and its Newey-West standard error;
2. report the automatic-bandwidth diagnostics listed above;
3. save the Python script as `code/q3_b.py`.




# Q3c

## Raw data

Use `data/EQ Dataset.csv`.

Also use the out-of-sample expected excess equity return forecast from Question 2(e) of Problem Set 1.

Use:

- `re` = annual log equity market return
- `rf` = annual log risk-free return
- the out-of-sample forecast of excess equity return from PS1 Q2(e)

---

## Data preparation

1. Construct the gross wealth return

Rw_t
= exp(re_t).

2. Construct the gross risk-free return

Rf_t
= exp(rf_t).

3. Construct the excess return on the wealth portfolio

xRw_t
= Rw_t - Rf_t.

4. Calculate the unconditional variance of the equity return over the full sample:

sigma_e^2
= Var(Rw_t).

5. Construct the trading instrument

z_{t-1}
= E^OS_{t-1}[xRe_t] / sigma_e^2.

Align the out-of-sample forecast so that the forecast formed at t-1 is matched with the realized excess return at t.

6. Construct the managed-portfolio excess return

z_{t-1} * xRw_t.

---

## GMM estimation

1. Use the two unconditional SDF moment conditions

E[Rw_t^(-gamma) * xRw_t]
= 0,

and

E[Rw_t^(-gamma) * z_{t-1} * xRw_t]
= 0.

2. Define the moment vector

g_t(gamma)
=
[
  Rw_t^(-gamma) * xRw_t,
  Rw_t^(-gamma) * z_{t-1} * xRw_t
]'.

3. Define the sample mean moment vector

g_bar(gamma)
= mean(g_t(gamma)).

4. Estimate gamma by GMM using the identity weighting matrix:

gamma_hat
= argmin_gamma
  g_bar(gamma)' * g_bar(gamma).

5. Calculate the standard error of gamma_hat using the same Newey-West procedure as in Q3b.

---

## Pricing errors

1. Evaluate the two sample moment conditions at gamma_hat.

These are the pricing errors:

alpha_hat
= g_bar(gamma_hat).

2. Calculate the standard error and t-statistic for each pricing error.

3. Report the pricing error and t-statistic for:

- the wealth portfolio moment;
- the managed-portfolio moment.

---

## Joint test

Test the null hypothesis that the two pricing errors are jointly zero.

Use the chi-square pricing-error test based on the estimated covariance matrix of the pricing errors.

Report the p-value of the joint test.

---

## Report

Report:

- gamma_hat
- Newey-West standard error of gamma_hat
- pricing error for each moment condition
- t-statistic for each pricing error
- p-value for the joint chi-square test
- T

---

## Output

1. save a table containing gamma_hat, its standard error, the two pricing errors and their t-statistics, and the joint-test p-value as `results/q3c_results.tex`;
3. save the Python script as `code/q3_c.py`.
