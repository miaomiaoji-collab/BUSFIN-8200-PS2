# Q2a

## Raw data

Use 'data/Portfolios_Formed_on_BE-ME.csv'.
Use 'data/ff3.csv'.

Use the monthly value-weighted returns for the 10 book-to-market decile portfolios from 'Portfolios_Formed_on_BE-ME.csv':

- Lo 10
- 2-Dec
……
- 9-Dec
- Hi 10

Use the sample from July 1927 to the latest common available month.
Use RF from 'ff3.csv' as the risk-free return.

---

## Data preparation

1. Merge the BM portfolio returns and RF by month.
2. Convert all returns from percent to decimal.
3. For each portfolio j, calculate the excess return

xR_{j,t}
= R_{j,t} - RF_t.

Define
xR_t
= [xR_{1,t}, ..., xR_{10,t}]'.

4. Calculate the sample mean vector

mu_hat
= mean(xR_t).

5. Calculate the sample covariance matrix

Sigma_hat
= Var(xR_t).

using divisor T (`ddof=0`).

6. Calculate the coefficients of the maximum SR portfolio formed from the 10 BM portfolios

b_hat
= Sigma_hat^(-1) * mu_hat.

7. Construct

xR_t^*
= b_hat' * xR_t.

It should be a time series

8. Use the normalization

E[M^*] = 1.

Since

M_t^*
= a - b_hat' * xR_t,

calculate

a_hat
= 1 + b_hat' * mu_hat.

Then construct

M_t^*
= a_hat - b_hat' * xR_t.

9. Check that the SDF prices the 10 BM excess returns in sample:

where mean(M_t^* * xR_t)
approximately equals 0.

10. Create a scatterplot:

- x-axis: BM portfolio decile = 1, ..., 10
- y-axis: b_hat coefficient for each portfolio


---

## Output

1. save the scatterplot as `output/q2a_b_coefficients.pdf`;
2. save the Python script as `code/q2_a.py`.
3.save the SDF time series as `output/q2a_M_star.csv`;

# Q2c

## Raw data

Use `data/Portfolios_Formed_on_BE-ME.csv`.
Use `data/10_Portfolios_Prior_12_2.csv`.
Use `data/ff3.csv`.

Use the 10 book-to-market decile portfolios and the 10 momentum decile portfolios.
Use the sample from July 1927 to the latest common available month.
Use RF from `ff3.csv` as the risk-free return.

---

## Data preparation

1. Merge the BM portfolios, momentum portfolios, and RF by month.

2. Convert all returns from percent to decimal.

3. For each portfolio, calculate the excess return

xR_{j,t}
= R_{j,t} - RF_t.

Combine the 10 BM portfolios and 10 momentum portfolios into

xR_t
= [xR_{BM,t}', xR_{MOM,t}']'.

This gives 20 excess returns for each month.

4. Calculate

mu_hat
= mean(xR_t),

and

Sigma_hat
= Var(xR_t),

using divisor T (`ddof=0`).

5. Calculate

b_hat
= Sigma_hat^(-1) * mu_hat.

6. Construct the excess return of the maximum Sharpe ratio portfolio:

xR_t^*
= b_hat' * xR_t.

7. Use the normalization

E[M^*] = 1.

Calculate

a_hat
= 1 + b_hat' * mu_hat,

and construct

M_t^*
= a_hat - b_hat' * xR_t.

It should be a time series.

8. Check that

mean(M_t^* * xR_t)

is approximately 0 for all 20 portfolios.

9. Create a scatterplot of the 20 b_hat coefficients:

- x-axis: portfolio decile = 1, ..., 10
- y-axis: b_hat coefficient
- BM portfolios: blue
- momentum portfolios: red

Plot both groups in the same figure.

10. Calculate the Sharpe ratio of xR_t^* from:

- Q2a: BM portfolios
- Q2b: momentum portfolios
- Q2c: BM and momentum portfolios combined

Use

Sharpe ratio
= mean(xR_t^*) / std(xR_t^*).

Calculate `std(xR_t^*)` using divisor T (`ddof=0`) to keep the
Sharpe ratio calculation consistent with the covariance matrix.

Report the three Sharpe ratios.

---
