# Q2a

## Raw data

Use 'data/Portfolios_Formed_on_BE-ME.csv'.
Use 'data/ff3.csv'.

Use the monthly value-weighted returns for the 10 book-to-market decile portfolios from 'Portfolios_Formed_on_BE-ME.csv':

- Lo 10
- 2-Dec
……
- 9-Dec
- Hi 10

Use the sample from July 1927 to the latest common available month.
Use RF from 'ff3.csv' as the risk-free return.

---

## Data preparation

1. Merge the BM portfolio returns and RF by month.
2. Convert all returns from percent to decimal.
3. For each portfolio j, calculate the excess return

xR_{j,t}
= R_{j,t} - RF_t.

Define
xR_t
= [xR_{1,t}, ..., xR_{10,t}]'.

4. Calculate the sample mean vector

mu_hat
= mean(xR_t).

5. Calculate the sample covariance matrix

Sigma_hat
= Var(xR_t).

using divisor T (`ddof=0`).

6. Calculate the coefficients of the maximum SR portfolio formed from the 10 BM portfolios

b_hat
= Sigma_hat^(-1) * mu_hat.

7. Construct

xR_t^*
= b_hat' * xR_t.

It should be a time series

8. Use the normalization

E[M^*] = 1.

Since

M_t^*
= a - b_hat' * xR_t,

calculate

a_hat
= 1 + b_hat' * mu_hat.

Then construct

M_t^*
= a_hat - b_hat' * xR_t.

9. Check that the SDF prices the 10 BM excess returns in sample:

where mean(M_t^* * xR_t)
approximately equals 0.

10. Create a scatterplot:

- x-axis: BM portfolio decile = 1, ..., 10
- y-axis: b_hat coefficient for each portfolio


---

## Output

1. save the scatterplot as `results/q2a_b_coefficients.pdf`;
2. save the Python script as `code/q2_a.py`.
3.save the SDF time series as `results/q2a_M_star.csv`;

# Q2e

## Raw data

Use the same 20 excess return portfolios from Q2c:
- 10 book-to-market decile portfolios
- 10 momentum decile portfolios

Use the sample from July 1927 to the latest common available month.
Use RF from `data/ff3.csv` as the risk-free return.

---

## Data preparation

1. Merge the 10 BM portfolios, 10 momentum portfolios, and RF by month.

2. Convert all returns from percent to decimal.

3. For each portfolio, calculate

xR_{j,t}
= R_{j,t} - RF_t.

Combine the 20 excess returns into

xR_t
= [xR_{BM,t}', xR_{MOM,t}']'.

4. Split the sample into:

- estimation sample: July 1927 to December 1989
- out-of-sample period: January 1990 to the latest common available month

5. Using only the estimation sample, calculate

mu_hat_IS
= mean(xR_t),

and

Sigma_hat_IS
= Var(xR_t),

using divisor T (`ddof=0`).

6. Estimate

b_hat_IS
= Sigma_hat_IS^(-1) * mu_hat_IS.

7. Using the normalization

E[M^*] = 1,

calculate

a_hat_IS
= 1 + b_hat_IS' * mu_hat_IS.

8. Keep a_hat_IS and b_hat_IS fixed.

For each month in the out-of-sample period, construct

M_t_OS^*
= a_hat_IS - b_hat_IS' * xR_t.

This should be an out-of-sample SDF time series from January 1990 onward.

9. For each of the 20 portfolios, calculate the out-of-sample pricing error

alpha_hat_p_OS
= mean_OS(xR_{p,t}) - Cov_OS(-M_t_OS^*, xR_{p,t}).

Use divisor T (`ddof=0`) when calculating the covariance.

10. Create a table with one row for each of the 20 portfolios and report

- portfolio name
- out-of-sample pricing error


---

## Output

1. save the LaTeX table as `results/q2e_pricing_errors.tex`;
2. save the Python script as `code/q2_e.py`.
